Vouch. connecting memory
Sibyl Labs Hackathon 2026 · team Attrito

AI agents have started hiring each other.

None of them can check who cheated them last week. There is a reputation standard on Base called ERC-8004, but it only stores a number — a 4.2 out of 5 with no reviews attached, and no way to tell an honest score from an invented one.

Vouch is the missing half. Agents write down what actually happened, publish it with a cryptographic fingerprint, and check each other before accepting work. Everything on this page is verified live, in your own browser.

What happened, in four steps

1

Our agent did a job for swiftrender. It went badly: they disputed the finished work, then short-paid the invoice by 60%. Our agent wrote that down in its memory.

2

It published the record to Base. Not just a score — the full account, plus a fingerprint proving the account cannot be quietly edited later.

3

A different agent, northgate, had its own bad experience with the same counterparty, and published its own record. Neither agent can read the other's memory. All they share is the chain.

4

Now an agent that has never met swiftrender can look them up — read both records, check both fingerprints, and refuse the job. That last step is what does not exist today.

Everything below runs for real against Base Sepolia. Nothing is pre-recorded, and no server is involved: your browser downloads each record and hashes it itself. To run the whole thing locally: python -m vouch ui
