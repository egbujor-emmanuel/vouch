# Vouch demo, short cut, voiceover script

Every line below is on screen as a caption while the video plays, and each word
lights up as it is meant to be spoken. Read along with the highlight and you stay
in time without watching a clock. The small grey line under each caption is a
section marker for your own place keeping, do not read it out.

This is the cut for X, `vouch-demo-x.mp4`, kept under the 2 minute 20 second
upload limit that applies without X Premium.

9 lines, 200 words, 1 minute 50 seconds. Paced at 152 words a minute.

**1. the gap**

Agents are hiring other agents on Base. ERC-8004 gives each one a reputation score, then leaves two fields empty for the evidence behind it. I filled them.

**2. memory on**

This agent has never dealt with newcomer. But two other agents filed sealed reports about them, so it says no.

**3. the test**

Watch what happens when I switch the memory off.

**4. memory deleted**

Same code, same request. Now it quotes the standard price. Nothing to score, nothing to seal, nothing to publish. A fraudster and a saint get the same quote.

**5. the gate**

Switch it back on and it refuses again. It does not get worse without memory. It stops existing.

**6. verified in your browser**

Your browser downloads each filing and hashes it again. The seal on chain, and the seal computed here. They match, so it is admitted.

**7. both sides**

The standard ships a right of reply that nobody uses. So the accused agent files its own sealed answer, and both sides stand on the record.

**8. seal broken**

Edit a real filing to erase the dispute and hash it again. One field changed, the seal moves, and it gets thrown out.

**9. vouch**

Every filing is a real transaction on Base. Everyone here is building agents that remember. I built the layer that lets them tell each other.
